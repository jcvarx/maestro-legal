Maestro

A local, approval-first artist-management tool.

Maestro helps an independent musician prepare and manage social media campaigns from a release folder — audio, artwork, lyrics, and video — and connect to social platforms when the artist chooses to. It runs locally, on the artist's own computer, and never publishes or posts anywhere without the artist's explicit, human approval.

How it works

  1. The artist provides release material (audio, artwork, lyrics, and optionally video) in a local folder.
  2. Maestro drafts platform-specific content — captions, titles, descriptions — grounded in that material.
  3. The artist reviews and approves (or edits, or rejects) each draft. Nothing moves forward without this step.
  4. Only for content the artist has approved, Maestro prepares a platform-specific package (for example, a TikTok post or a YouTube video).
  5. Publishing itself requires a second, separate, explicit approval — creative approval and publishing approval are never the same step.
  6. Only then does Maestro send the approved content to the connected platform, using that platform's own official API.

Connected platforms

Maestro can connect to Instagram, TikTok, and YouTube, each only when the artist explicitly authorizes that specific connection. Maestro uses each platform's official API directly — no browser automation, no unofficial endpoints. See the Privacy Policy for exactly what data is involved in each connection.

Who this is for

Maestro is currently an early-stage private beta, built for and used by one independent artist. It is not yet a public product.
